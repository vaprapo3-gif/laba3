# Лабораторна робота №3
## Варіант 8

### Опис задачі
Обчислити добуток мінімального елемента матриці 4×4 на середнє арифметичне всіх елементів матриці.

### Алгоритм розв’язання
1. Ввести елементи матриці 4×4
2. Вивести матрицю
3. Знайти мінімальний елемент
4. Обчислити суму всіх елементів
5. Знайти середнє арифметичне
6. Обчислити добуток
7. Вивести результат

### Основні етапи роботи програми
- Ввід даних з клавіатури
- Обробка масиву (пошук мінімуму та середнього)
- Вивід результатів
